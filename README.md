### 🚀 Projects

**[Salah Times](#)** — Prayer-times mobile app, published on the Play Store
Migrated the core API from Firebase to a custom TypeScript/Hono/Turso backend; built city/district masjid filtering, an OTP-based auth flow, and an OCR pipeline (Tesseract/EasyOCR/PaddleOCR + Gemini Vision fallback) for reading prayer times off mosque LED boards.

**[NexCart](#)** — Wholesaler-focused B2B/B2C e-commerce platform (final-year project)
Multi-tenant platform with RFQ negotiation, tiered pricing, and credit ledger management (PostgreSQL + Prisma + Razorpay). Includes an AI Business Advisor built on RAG (ChromaDB, LangChain, Gemini API), an AI Khatta Digitizer that extracts structured data from handwritten ledgers, and a hybrid recommendation engine (TF-IDF + collaborative filtering + time-decay popularity).

**[DocMind](#)** — AI document intelligence platform *(in progress)*
Upload PDFs/DOCX/TXT for AI summaries, RAG-based chat with documents, quiz/flashcard generation, and semantic search. React/TS frontend, Node/Express backend, Python/FastAPI + LangChain + FAISS AI service.

**[Resume Analyzer](#)** — AI-powered resume analysis tool
FastAPI backend with an MCP server layer, Gemini API for analysis, and a React/TanStack Query/Zustand frontend.

**GLP 101** — Health education web platform, built at Eonyx Infotech LLP for HealthTales LLC. React/Tailwind frontend with multi-locale support.
